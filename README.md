# Neon Lluvia — Android pixel-art cyberpunk

Prototipo de aventura 2D vista desde arriba, con una ciudad procedural, lluvia, reflejos de neón, edificios con ventanas, NPCs, minimapa, créditos, energía, un puesto de ramen y encargos.

## Controles
- PC: WASD o flechas para moverte, E para interactuar, M para abrir/cerrar mapa.
- Android: joystick táctil abajo a la izquierda y botón USAR abajo a la derecha. Tocá el botón de mapa en la esquina superior derecha.

## Abrir y probar
1. Instalá Godot 4.3 o superior.
2. Importá esta carpeta como proyecto y ejecutá `main.tscn`.
3. Para crear un APK, configurá las plantillas de exportación Android en Godot y un Android SDK/JDK compatible.

## Crear APK con GitHub Actions
1. Creá un repositorio en GitHub y subí todos los archivos de esta carpeta.
2. En GitHub, abrí **Actions** y ejecutá el workflow **Build Android APK**.
3. Descargá el APK desde **Artifacts** al terminar.

Este repositorio genera un APK de depuración para pruebas. No es una publicación firmada para Google Play.
